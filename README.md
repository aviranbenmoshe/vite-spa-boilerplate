# Vite SPA Boilerplate

A modern boilerplate for single page applications built with Vite.

## Features

- ⚡️ Fast development with Vite
- 🎯 Modern JavaScript/TypeScript support
- 🔥 Hot Module Replacement (HMR)
- 📦 Optimized build output
- 🛠️ ESLint and Prettier configuration
- 🎨 CSS preprocessing support

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/aviranbenmoshe/vite-spa-boilerplate.git
   cd vite-spa-boilerplate
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## Project Structure

```
vite-spa-boilerplate/
├── public/          # Static assets
├── src/             # Source code
│   ├── components/  # Reusable components
│   ├── styles/      # CSS/SCSS files
│   ├── utils/       # Utility functions
│   ├── main.js      # Application entry point
│   └── index.html   # HTML template
├── package.json     # Dependencies and scripts
└── vite.config.js   # Vite configuration
```

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
- `npm run format` - Format code with Prettier
